# Elora 首页视频流与非首页目录

- 首页设计：[Figma 1:2](https://www.figma.com/design/CpV8PTHxU293dAGBeENzJD?node-id=1-2)。`HomeVideoFeedScreen` 提供VerticalPager，支持上滑下一条、下滑上一条。只有当前页创建播放媒体，离开前台按既有播放器生命周期暂停，离开页释放播放器；暂停与播放切换不覆盖媒体错误重试控件。
- 首页导航4为默认入口；保留视频0、图片1、充值2、个人3。四个主导航按首页/视频/图片/个人展示，充值从余额与Elora入口进入。旧个人/充值等页面也复用统一导航，能直接回首页。
- 依据已核对契约 `docs/core-rebuild/kit/contracts/视觉生成接口接入.md`，运行中使用的AchatBackendClient：视频首页显式 `home_featured=true`，非首页视频显式false，图片和分类接口不传。刷新、重试及分页保持相同条件，不用客户端局部过滤代替服务端分页。
- 两个瀑布流为非首页目录，筛选只有All与相应后台分类，索引0不传category_id、索引1+对应后台分类；不再硬编码Hot/Trending/New为分类。视频目录沿用hot排序、图片沿用latest。分类、报价、媒体和上传生成回调保持原契约。
- 首页与视频目录复用视频结果存储，但切换时清空并取消旧请求，用独立序号挡住迟到结果。Startup只产生首页视频数据；若当前位于非首页视频或有图片分类，按当前频道/分类重新请求，避免startup覆盖后分页混用。
- 首页Generating/Completed仅来自真实任务状态，不复制设计中的示例状态。首页曝光按可见页ID去重，后台/前台切换重新统计；分页追加不会重复曝光当前页。

## 本地验证

- 单元测试覆盖active client URL的home true/false、分页、分类保留及图片省略参数，导航允许首页4，频道标记和startup重载规则。
- 模拟器相关目录/首页/错误状态测试共7项：含上下双向滑动、模板选择、暂停切换、首页/视频/图片导航、后台分类ID、分页防重复/曝光和错误重试。
- UI测试使用本地图片fixture替代远程视频，验证页面状态和滑动；真实后台首页分配、CDN视频播放/解码与完整生成链路仍需真数据验收。上述本地验证不替代归因C01–C38平台/后端/发布证据。
- 跨模块完整设备套件已有AndroidJUnitRunner配置限制见此前记录，本轮执行app相关测试，不声称全项目设备套件通过。
